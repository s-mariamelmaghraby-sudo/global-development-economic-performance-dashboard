# Global Development & Economic Performance Dashboard | Power Bi 

An interactive Power BI project exploring global development indicators, economic performance, health, education, and country-level insights.

## About the Project

This project uses Power BI to transform data into interactive visualizations that make global indicators and economic patterns easier to explore. The report is organized into four main sections, providing both a high-level overview and more detailed insights.
